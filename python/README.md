# MatchApp Ai (Python)

Local companion. No pip install.

```bash
python app.py
```

Windows: double-click `Run-MatchApp-Ai-Preview.bat` for a stable local preview on port 8899 (or `run.bat` for the original automatic port). Opens http://127.0.0.1:8765/. Ctrl+C stops it.

Chrome or Edge can hear the mic. Any browser can play the voices and take a typed question. See `HANDOFF.md` before changing the face or voice path.
